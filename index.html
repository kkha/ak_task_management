    완료 히스토리

    통합설정

    할 일 내용에 아래 키워드가 들어 있으면 해당 카테고리로 자동 분류됩니다. 카테고리를 직접 바꾸면 그 내용이 자동으로 학습되어 여기에 쌓입니다.

    카테고리별 세부분류를 추가·이름변경·삭제합니다. 할 일을 추가·수정할 때 여기서 만든 세부분류를 고를 수 있고, 좌측 분류 트리에서 필터링됩니다.

    매일 자동으로 할 일을 내보내기합니다. 같은 파일명으로 덮어쓰므로 최신 백업만 유지됩니다.

    내보내기

    현재 모든 할 일과 설정을 JSON 파일로 저장합니다.

    가져오기

    이전에 저장한 JSON 파일을 불러옵니다. 기존 데이터에 병합됩니다.

    이 파일은 직접 열 수 없습니다

    여기 있는 index.html은 개발용 원본입니다. 아래 중 하나로 실행하세요.

    • 바로 열기: dist/index.html 를 더블클릭 (npm run build 로 생성)
    • 개발 서버: 터미널에서 npm run dev 실행 후 표시된 주소 열기
