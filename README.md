# Task Management

매일의 할 일을 날짜·주·월별로 관리하는 개인용 웹 앱. 계정·설치·네트워크 없이
브라우저만으로 동작하며, 데이터는 브라우저에 저장되어 새로고침·재방문 후에도 유지된다.
회사 PC에서는 `index.html` 을 더블클릭해 열고, 전용 아이콘 바로가기를 작업 표시줄에
고정해 쓸 수 있다 — [배포본](#배포본-회사-pc-등) 참고.

현재 버전은 앱 상단 제목과 브라우저 탭에 `Task Management v4.0.0`으로 표시된다
(`src/version.js`, `package.json`과 일치). 버전별 변경 내용은 [`CHANGELOG.md`](CHANGELOG.md).

## 기능

**레이아웃**
- **전체 폭 3단** — 좌: 카테고리·세부분류 트리 / 중: 월별 달력 + 메모 / 우: 선택 기간의 할 일 관리.
  ≤1180px는 트리를 "☰ 분류" 슬라이드오버로, ≤820px는 세로 스택.
- **월별 달력** — 주 번호(WK) 열(보라색), 오늘 강조, 할 일 있는 날 점 표시.
  클릭은 보기별로: 일별=날짜, 주별=WK 번호만(그 주 파란 밴딩), 월별=그 달 전체 밴딩.

**분류**
- 고정 카테고리 3종(개인 / 업무 / 공부) + **사용자 관리형 세부분류**(예: 업무 › 빅데이터,
  AI/자동화, UT일반, UT과제). "세부분류 편집" 창에서 카테고리별 추가·이름변경·삭제.
- 좌측 트리에서 카테고리/세부분류/미분류 클릭 → 목록 필터. 현재 보기 기준 개수 표시.
- **자동 분류** — 입력 키워드로 카테고리를 추측(규칙 기반, 오프라인). 직접 고르면 존중하고
  학습해 다음 분류에 반영. `분류 설정` 창에서 키워드 직접 관리.

**할 일**
- 추가 / 편집 카드(내용·카테고리·세부분류·우선순위·날짜·기간단위·메모) / 삭제.
- **상태 3단** — 대기 / **작업중**(옅은 회색 배경) / 완료(취소선). "진행" 토글 + 완료 체크박스.
- **우선순위** — 높음(좌측 빨강선 + 굵게 + ▲) / 보통 / 낮음(▼, 흐리게). `정렬: 우선순위순`.
- **상세메모** — 항목마다 "메모"로 펼치는 입력 칸(자동 저장).
- **여러 날** — 편집 카드에서 종료일 지정. 일별 보기에 "N일차", 주·월 보기에 "9/8–9/10" 뱃지.
- **반복** — 일별에서 매일 / 평일 / 매주(요일 선택). 8주치 생성 + 열 때마다 8주 앞까지 자동 연장.
  반복 항목은 🔁, 삭제 시 "이 항목만 / 이후 모두" 선택.
- **옮기기** — 편집 카드의 날짜·기간단위 필드로 다른 날/주/월로 이동. 주별 계획 → 특정 날 할당.

**보기 · 정렬**
- **일 / 주 / 월** 보기(하나의 통합 목록). 주별·월별에서 추가하면 그 주/달의 **계획**으로 등록
  (목록 맨 위, `WK37`·`9월` 뱃지). 정렬: 수동(드래그) / 우선순위순 / 날짜순 / 최신·오래된순 /
  카테고리순 / 진행 우선. 드래그 또는 핸들 포커스 후 `↑`/`↓`(수동 정렬일 때).
- 진행률(현재 보기 기준), **완료 항목 숨기기** 토글.

**기타**
- **완료 히스토리** — 앱 바 "히스토리". 완료 항목을 완료일별로 최근순(완료 시각·소요 시간·메모),
  내용 검색 + 완료일 기간 필터.
- **메모 스티커** — 좌측 달력 아래 자유 기록(자동 저장).
- **내보내기 / 가져오기** — 할 일을 JSON으로 백업·복원(교체 또는 병합).
- **테마** — 자동 / 밝게 / 어둡게.

## 실행 방법

### 그냥 열어보기

`npm run build` 후 생기는 `dist/index.html` 파일 하나를 더블클릭하면 기본 브라우저에서
바로 열린다. CSS·JS가 모두 안에 들어 있어 서버도, 인터넷 연결도 필요 없다.

### 배포본 (회사 PC 등)

```bash
npm run package
```

`release/AK Task Management/` 폴더(`index.html` + 전용 아이콘 `app-icon.ico` +
`AK Task Management.lnk` + `바로가기 만들기.cmd` + `변경이력.txt` + `사용법.txt`)와
`release/AK-Task-Management.zip` 이 생긴다. 폴더를 회사 PC로 복사한 뒤:

1. `index.html` 을 더블클릭 → 기본 브라우저에서 열림.
2. 작업 표시줄에 고정하려면 **`바로가기 만들기.cmd`** 를 한 번 실행(그 PC 경로에 맞는
   바로가기 생성) → **`AK Task Management`** 바로가기 우클릭 → "추가 옵션 표시" →
   **"작업 표시줄에 고정"**. (`.lnk` 대상이 `explorer.exe` 라 이 메뉴가 뜬다.)

데이터는 그 브라우저·그 PC에 로컬 저장된다. 다른 PC로 옮길 땐 "내보내기".

### 개발

```bash
npm install
npm run dev      # 개발 서버 (핫 리로드)
npm run build    # dist/index.html 생성 (단일 파일)
npm test         # 단위·통합 테스트 (Vitest)
npm run lint     # ESLint
npm run format   # Prettier
npm run screenshot  # 빌드 후 헤드리스 브라우저로 실제 화면 캡처 (scripts/screenshots/)
npm run icon        # 앱 아이콘 생성 (assets/app-icon.ico + index.html 파비콘 — 순수 Node)
npm run package     # 빌드 + 아이콘 + release/ 배포본(폴더 + zip + .lnk) 생성
```

## 데이터 저장 방식

- 브라우저 `localStorage`
  - `task-app.tasks` — 할 일 객체 배열. 필수: `{ id, text, category, completed, createdAt, date }`.
    선택 필드는 기본값이 아닐 때만 저장한다: `scope`(week/month), `status`("doing"),
    `priority`(high/low), `subcategory`, `endDate`(여러 날 종료일), `notes`, `doneAt`(완료 시각),
    `recurrence`+`series`(반복). 구 데이터는 로드 시 자동 보정, 모르는·모순된 값은 필드만 떼어낸다.
  - `task-app.subcategories` — `{ 개인: [], 업무: [...], 공부: [] }`. 첫 실행 시 업무만 시딩.
  - `task-app.prefs` — `{ filter, sort, hideCompleted, theme, view }`.
    `filter`는 `"전체"` | 카테고리 | `"카테고리/세부분류"` | `"카테고리/"`(미분류).
  - `task-app.memo` — 좌측 메모 스티커 문자열.
  - `task-app.classifier` — 사용자 추가·학습 분류 키워드.
- 모든 변경 시점에 저장. 지금 보고 있는 날짜는 저장하지 않는다(새로고침 시 오늘부터).
- 저장 위치는 **이 브라우저, 이 기기**뿐. 사이트 데이터를 지우면 할 일도 사라진다 — 백업은 **내보내기**.
- 시크릿 모드 등 저장이 막힌 환경에서는 그 세션만 동작(앱은 정상 실행).
- 손상된 값·잘못된 가져오기 항목은 유효한 것만 남기고 조용히 버린다.
